Quora Post App

A simple full-stack CRUD application inspired by Quora, where users can create, view, edit, and delete posts. Built with React on the frontend and Express on the backend.

Features
View all posts
View a single post by ID
Create a new post with a username and content
Edit/update an existing post's content
Delete a post
Tech Stack

Frontend

React
Axios (for API requests)
Vite

Backend

Node.js
Express
UUID (for generating unique post IDs)
CORS
